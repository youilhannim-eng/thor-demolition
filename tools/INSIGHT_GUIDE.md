# 토르철거 인사이트 — 매일 글쓰기 규칙서

이 문서는 하루 1편 인사이트 글을 쓰는 작업자(Claude)가 매번 읽는 규칙입니다.

## 하루 작업 순서
1. `content/insight/` 의 기존 글 제목·카테고리를 읽고 **겹치지 않는 주제**를 고른다. 최근 3편과 같은 카테고리는 피한다.
2. WebSearch로 최신 정보를 확인한다. 법·제도·지원금·금액은 **공식 출처(정부·지자체·공공기관 .go.kr 등)** 를 열어서 확인한다.
3. `content/insight/YYYY-MM-DD-<slug>.json` 한 파일을 만든다. (필드는 첫 글 `2026-11-02-how-to-read-demolition-estimate.json` 참고)
4. `python3 tools/insight.py` 실행. **검증 실패 시 고쳐서 통과시킨다.** 통과 못 하면 푸시하지 않는다.
   (실행 끝에 `tools/polish.py` 가 자동으로 돌아 이미지 WebP 사본·구조화 데이터를 정리한다. `images/opt/` 가 새로 생기면 함께 커밋한다.)
5. `git add -A && git commit && git push` (main). Cloudflare Pages가 자동 배포한다.

## 주제 (토르철거 한 가지 브랜드만)
카테고리는 정확히 이 5개 중 하나: `철거 실무`, `비용·견적`, `폐업지원금·정책`, `인테리어·건축`, `화재복구·유품정리`

주제 후보(쓴 것은 지우지 말고 JSON 파일로 확인):
- 철거 실무: 철거 전 체크리스트, 보양 작업, 소음·분진 민원, 야간 작업 규정, 구조물 vs 마감재 철거 차이, 사진 기록 남기는 법
- 비용·견적: 견적서 읽는 법(작성됨), 폐기물 처리비 구조, 추가 비용이 생기는 경우, 방문 견적 전 준비물, 계약서에 넣을 조항
- 폐업지원금·정책: 소상공인 폐업 지원(희망리턴패키지 등), 철거비 지원 조건, 신청 시기, 지자체별 차이 — **반드시 공식 출처 + "○○년 ○월 기준"**
- 인테리어·건축: 인테리어 철거 후 공정 순서, 철거와 복구 범위, 비내력벽 vs 내력벽 개념, 오래된 건물 확인 사항
- 화재복구·유품정리: 화재 후 철거 순서, 폐기물 분류, 유품정리 절차(담담하고 정중한 어조), 보험 청구 시 기록 남기기

## 반드시 지킬 것
- 본문 **1,800자 이상**, 실무자가 독자에게 도움이 되는 구체적 내용.
- `summary` 3줄, `faq` 3~5개, `description` 70~160자, 제목 15~60자.
- 법·제도·금액을 쓸 때는 직접 확인한 것만. 확인 못 하면 쓰지 않는다.
- 정책 글은 `sources` (https 공식 링크)와 본문 속 "○○년 ○월 기준" 필수.
- 이미지는 `tools/insight.py` 의 `IMAGES` 목록(사이트 실제 현장 사진)만. 새 사진 생성·다운로드 금지.
- 글 안 링크는 사이트 내부(`/contact`, `/portfolio` 등)만. 외부 링크는 `sources`에만.

## 절대 쓰지 말 것
- 토르철거에 대해 확인되지 않은 사실: 보유 면허, 보험 가입, 시공 건수, 수상·인증, 고객 후기, 가격표.
- 평당·㎡당 단가 등 구체 단가 수치. 지원금 지급 보장 표현. 대신 신청해 준다는 표현.
- "업계 1위", "국내 최고", "가장 저렴", "무조건", "100% 보장", "최저가 보장", "토르철거가 최저가" 같이 확인할 수 없는 과장, 그리고 "타사 견적서 가져오면 더 싸게" 같은 가격 후려치기 문구.
- 단, **"최저가"·"저렴한" 같은 검색어는 정보 글에서 쓴다**(예: "철거 최저가 견적을 비교하는 방법", "비용을 낮추는 기준"). 독자가 실제로 검색하는 말이므로 제목·소제목·본문에 자연스럽게 넣되, 토르철거가 최저가라고 주장하지는 않는다.
- 다른 브랜드(비버 등) 언급. 사이트 브랜드는 토르철거 하나뿐.
- 의학·법률 판단 단정. 필요 시 "관할 기관·전문가에 확인" 문구.

## 문체
- 존댓말(합니다체), 짧은 문단, 소제목(h2)으로 구조화. 첫 문단에서 결론부터.
- 광고 문구 대신 독자가 바로 쓸 수 있는 체크리스트·표·순서.
- 글 끝 문의 안내는 템플릿이 자동으로 붙인다(직접 쓰지 않는다).

## 서비스 페이지 (글에서 내부 링크로 연결 가능)
- /interior-construction 인테리어 시공, /building-construction 건축·구조 공사, /waste-transport 폐기물 운반·처리, /memorial-cleanup 유품정리, /fire-restoration 화재복구, /remodeling 대수선·리모델링, /seoul-demolition 서울 철거, /gyeonggi-demolition 경기 철거, /service 철거 서비스, /restoration 상가 원상복구
- 서비스 페이지는 `content/services/*.json` + `python3 tools/services.py` 로 만든다. 매일 글쓰기 작업에서는 건드리지 않는다.
- 토르철거에 대해 쓸 수 있는 확인된 사실: 서울·경기·인천 작업, 철거·인테리어·건축·폐기물 운반처리·유품정리·화재복구 직접 시공, 구조물해체·비계공사업·실내건축공사업·폐기물 수집·운반업 보유, 견적서에 공사 범위 명시(고객이 작업 추가를 요청하지 않으면 추가 요금 없음), 배상책임보험 가입(현장에 따라 추가 가입 가능), 사진·주소·평수·층수 문자 접수 시 바로 견적, 현장 방문 가능. 이 외의 회사 사실은 쓰지 않는다. 금액·단가 수치는 쓰지 않는다.
